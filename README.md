# Chat Web

Một ứng dụng trò chuyện đơn giản trên nền web.

## Tính năng

- Nhắn tin thời gian thực
- Xác thực người dùng
- Thiết kế đáp ứng trên nhiều thiết bị

## Cài đặt

```bash
git clone https://github.com/yourusername/chat_web.git
cd chat_web
npm install
```

## Sử dụng

```bash
npm start
```

Mở trình duyệt và truy cập `http://localhost:3000`.

## Công nghệ sử dụng

- Node.js
- Express
- Socket.io
- React
